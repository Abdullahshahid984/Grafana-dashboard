## Check the Actual ConfigMap Currently Deployed:

```powershell
kubectl get configmap profilebatchservice-api-config -n api-accountlookupexperience-v1 -o yaml
```

**Look for:** Is `secretProviders` nested inside this ConfigMap? (It shouldn't be - ConfigMaps only support strings)

---

## Check All ConfigMaps in the Namespace:

```powershell
kubectl get configmaps -n api-accountlookupexperience-v1
```

---

## View Full ConfigMap Data (formatted):

```powershell
kubectl get configmap profilebatchservice-api-config -n api-accountlookupexperience-v1 -o jsonpath='{.data}' | Format-List
```

## Check for Deployment Errors in Events:

```powershell
kubectl get events -n api-accountlookupexperience-v1 --sort-by='.lastTimestamp' | Select-String -Pattern "Error|Failed|Invalid" | Select-Object -Last 20
```
