Hi Gabriel, adding to what Anit said. You'll need to raise your own CR for the APIM deployment. These are the main fields:
- **Configuration item:** the API CI, as Anit said. Add the APIM instance (`<External or Internal>`) if the form allows.
- **Impacted services:** the APIs and products changed in release 2026-NOV-REL1 `<list>`, and their consumers.
- **Implementation plan:** deploy `release/2026-NOV-REL1` through the release pipeline in the window `<date and time>`, then verify the changed operations.
- **Backout plan:** redeploy the previous release tag, then validate calls.
- **Test plan:** call the changed operations through APIM and watch the gateway logs for errors.
- **Approvers:** the change manager and the APIM owner, plus the pipeline approvers.
CHG0113759 (Account Center, same release) is a good example of how the fields are worded. It's their CR, so please don't attach your work to it.
