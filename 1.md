**From your local machine, check the cluster DNS configuration:**

```bash
# Check CoreDNS pods
kubectl get pods -n kube-system | grep coredns

# Check if they're running
kubectl describe pod -n kube-system <coredns-pod-name>

# Check the service
kubectl get svc -n kube-system coredns

# Check node DNS config
kubectl get node -o wide
# Then check if nodes can resolve external DNS
kubectl debug node/<node-name> -it --image=ubuntu
```
