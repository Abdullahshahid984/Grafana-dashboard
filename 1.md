```
ApiManagementGatewayLogs
| where TimeGenerated between (datetime(2026-11-06T05:00:00Z) .. datetime(2026-11-06T17:30:00Z))
     or TimeGenerated between (datetime(2026-11-05T05:00:00Z) .. datetime(2026-11-05T17:30:00Z))
| extend period = iff(TimeGenerated >= datetime(2026-11-06), "Fri with Traceable", "Thu without")
| extend size_bucket = case(RequestSize < 10000, "1 under 10KB", RequestSize < 131072, "2 10KB-128KB", RequestSize < 1000000, "3 128KB-1MB", "4 over 1MB")
| summarize requests=count(), p50_ms=percentile(TotalTime-BackendTime,50), p95_ms=percentile(TotalTime-BackendTime,95),
            p99_ms=percentile(TotalTime-BackendTime,99), over_8s=countif((TotalTime-BackendTime)>8000)
            by size_bucket, period
| order by size_bucket asc, period asc
```
