```
1. Open the APIM instance, then go to Products (left menu, under APIs) and click + Add.
2. Fill in the Display name, an Id (the short name used in URLs and scripts) and a Description.
3. Set the state to Published if consumers should be able to call it right away (leave it unpublished while you prepare).
4. Requires subscription: turn on, so callers need a key.
5. Requires approval: leave off for a bot or internal product, turn on if requests need approval. Optionally set a subscription count limit.
6. In the APIs section, add the APIs the product should expose, then click Create.
7. To give a consumer access, go to Subscriptions, click + Add subscription, set the scope to the product, name it, pick the user or bot and create it. Copy the keys straight into the secure place they belong. Never paste keys into chat or tickets.
```
