# Fix: Resolve AKS Cluster upgrade_override Unset Error

## Premise

Terraform apply fails in AKS POC environment with:
```
Error: 'upgrade_override' cannot be unset
```

**Root Cause:** Azure has `upgrade_override` configured, but Terraform tries to remove it (unset) because the config doesn't define it. Azure doesn't allow unsetting this attribute.
---

## Solution
Add `upgrade_override` to `ignore_changes` in the AKS cluster module lifecycle block.

**File Changed:**
```
bfhaksplatform/terraform/modules/main/modules/aks_cluster/main.tf
```

**Before:**
```terraform
lifecycle {
  ignore_changes = [
    kubernetes_version,
    service_mesh_profile[0].revisions
  ]
}
```

**After:**
```terraform
lifecycle {
  ignore_changes = [
    kubernetes_version,
    service_mesh_profile[0].revisions,
    upgrade_override  # ← NEW
  ]
}
```
