Got some good news on the backup/restore front. We've been dealing with the OIDC federated credential issue for a while, and I finally got it working end-to-end.

Basically, the problem was that when we restored workloads to a new cluster, they couldn't authenticate because the federated credentials for that cluster's OIDC issuer didn't exist. So I built automation into the workload onboarding pipeline to handle this automatically. It detects which environment is running, maps it to the restore target cluster, queries that cluster's OIDC issuer, and creates the right federated credentials on the source cluster's MIs.

First round of testing went really well restored all 71 namespaces from DEV to POC2, and everything authenticated without any 401 errors. Validated it works at scale.

Now we're moving into the next phase with DEV-RST. I have raised two PRs one to provision the cluster in the DEV resource group, and one to extend the automation to support DEV-RST as a restore target. Once those get merged, we can test the full DR workflow.
