Restore validation workspace for Phase 1 reads DEV workload identity outputs 
and instance configuration for use by the restore Phase 2 workspace. 
Used to create Workload Identity federated credentials on DEV Managed Identities 
for additional clusters (e.g. POC-02) during backup and restore validation. 
This workspace is isolated from the shared DEV phase1 workspace and should only 
be triggered manually during restore validation exercises.
