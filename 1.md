**1. The deployed policy** (writes straight to a file, then checks it isn't empty):
```powershell
az rest --method get --url "https://management.azure.com$apimId/policies/policy?api-version=$api&format=rawxml" --output-file allapis-policy.xml
(Get-Item allapis-policy.xml).Length
Select-String -Path allapis-policy.xml -Pattern "traceable|ext_cap|send-request|send-one-way|timeout=|ignore-error|module-version" -Context 0,1
```
```powershell
$tok = az account get-access-token --resource https://management.azure.com --query accessToken -o tsv
Invoke-RestMethod -Uri "https://management.azure.com$apimId/policies/policy?api-version=$api&format=rawxml" -Headers @{Authorization="Bearer $tok"} -OutFile allapis-policy.xml
(Get-Item allapis-policy.xml).Length
Select-String -Path allapis-policy.xml -Pattern "traceable|ext_cap|send-request|send-one-way|timeout=|ignore-error|module-version" -Context 0,1
```

**2. The activity log, case-insensitive and with more events:**
```powershell
$start = (Get-Date).AddDays(-60).ToUniversalTime().ToString("yyyy-MM-ddTHH:mm:ssZ")
az monitor activity-log list --resource-id $apimId --start-time $start --max-events 1000 -o json |
  ConvertFrom-Json |
  Where-Object { $_.operationName.value -match 'policies|policyFragments|namedValues' } |
  Select-Object @{n='time';e={$_.eventTimestamp}}, @{n='op';e={$_.operationName.value}}, @{n='by';e={$_.caller}}, @{n='status';e={$_.status.value}} |
  Format-Table -AutoSize
```
