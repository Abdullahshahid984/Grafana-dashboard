
**1. Find a workspace** (the subscription is already set)

```powershell
az monitor log-analytics workspace list --query "[].{name:name, rg:resourceGroup, id:customerId}" -o table
```


```powershell
az monitor diagnostic-settings subscription list --query "value[].{name:name, workspace:workspaceId}" -o table
```

**2. Run the query** (replace `<workspace-id>` with the `id` / customerId from step 1)

```powershell
az monitor log-analytics query --workspace "<workspace-id>" --analytics-query "AzureActivity | where ResourceProviderValue =~ 'MICROSOFT.APIMANAGEMENT' | where OperationNameValue has 'namedValues/write' | where _ResourceId has 'apim-ads-cus-entbusops-prd-ext-apim-001' | project TimeGenerated, Caller, OperationNameValue, ActivityStatusValue | order by TimeGenerated asc" --timespan "P365D" -o table
```
