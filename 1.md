The NSG name or resource group doesn't match. Let me help you find the correct one:

```powershell
# First, get the actual node resource group
$nodeRG = az aks show -g <your-resource-group> -n <your-cluster-name> --query nodeResourceGroup -o tsv
Write-Host "Node Resource Group: $nodeRG"

# List all NSGs in that resource group
az network nsg list -g $nodeRG -o table
```

Run that and it will show you the actual NSG names. Then use the correct name:

```powershell
# Once you have the correct NSG name, list outbound rules
az network nsg rule list -g $nodeRG --nsg-name "<correct-nsg-name>" --query "[?direction=='Outbound']" -o table
```

Or to see all rules with port 53:

```powershell
az network nsg rule list -g $nodeRG --nsg-name "<correct-nsg-name>" -o json | ConvertFrom-Json | Where-Object { $_.destinationPortRange -like "*53*" -or $_.destinationPortRange -eq "*" } | Select-Object name, direction, access, destinationPortRange, sourcePortRange
```
