The api-transactions deployment in api-transactions-v1 namespace is failing with:
`"Failed to configure a DataSource: 'url' attribute is not specified and no embedded datasource could be configured"`

**Root Cause:**
The ConfigMap `api-transactions-config` is missing the `SPRING_DATASOURCE_URL` key. It only contains `CUSTOMERDB_URL`. Since the deployment spec uses `envFrom.configMapRef`, the app expects `SPRING_DATASOURCE_URL` as an environment variable, but it's not being injected.

**Evidence:**
Run this to verify:
```powershell
kubectl get configmap api-transactions-config -n api-transactions-v1 -o jsonpath='{.data}' | Select-String "SPRING_DATASOURCE_URL"
```
This returns nothing, confirming the key is missing.

**Required Fix:**
Add `SPRING_DATASOURCE_URL` to the ConfigMap with the SIT database connection string
