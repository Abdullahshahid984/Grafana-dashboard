**Premise**

Implements federated credential automation for AKS backup/restore validation. 
Solves Workload Identity OIDC issuer mismatch errors (AADSTS700211) that were blocking 
restored workloads from authenticating to Azure services.

## Changes from Previous PR
Previous approach (`TF_VAR_additional_clusters` via pipeline variables) did not work due to:
- Complex HCL value passing through environment variables in local execution mode
- Terraform not picking up the variable correctly
- Build artifact caching issues

**New approach:** Environment-based mapping in code
- Detects current environment from `conf.yaml`
- Maps environment to restore target cluster (e.g. dev → poc-02)
- Queries restore cluster's OIDC issuer URL
- Automatically creates federated credentials for all workloads

## Implementation Details
- File: `phases/02-per-instance-per-cluster/main.tf`
- Added: `restore_cluster_mapping` locals with environment → cluster mapping
- Added: `data.azurerm_kubernetes_cluster.additional_clusters` to query restore target
- Existing `kubernetes_resources` module handles federated credential creation
