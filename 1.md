```
1. Open the APIM instance and go to Subscriptions (left menu), then click + Add subscription.
2. Name and Display name: use the consumer’s name or bot name, so it’s clear who owns it.
3. Scope: choose Product, then pick the product. Use the product scope in most cases, so the key gets access to everything on that product. The other options, All APIs and a single API, give much broader or narrower access.
4. User: pick the owner (the bot or consumer account) if it has one. It is optional.
5. Leave Allow tracing off, especially in production.
6. Click Create.
7. Open the subscription and use Show/hide keys to read the primary and secondary key.
```
