## **Helm Chart Troubleshooting Guide**

### **1. Helm Release Status**
```bash
helm list -n <namespace>
helm status <release-name> -n <namespace>
helm history <release-name> -n <namespace>
helm get values <release-name> -n <namespace>
helm get manifest <release-name> -n <namespace>
```

### **2. Validate Chart Before Deployment**
```bash
helm lint ./my-chart
helm install <release-name> ./my-chart -n <namespace> --dry-run --debug
helm template <release-name> ./my-chart -n <namespace> -f values.yaml
```


### **3. Helm Chart Updates & Rollbacks**
```bash
helm upgrade <release-name> ./my-chart -n <namespace> -f values.yaml
helm upgrade <release-name> ./my-chart -n <namespace> --set image.tag=v2.0.0 --set replicaCount=3
helm rollback <release-name> -n <namespace>
helm rollback <release-name> <revision> -n <namespace>
```

### **4. Helm Chart Dependencies**
```bash
helm dependency update ./my-chart
helm dependency list ./my-chart
helm lint ./my-chart
```


**Helm release in failed state:**
```bash
helm delete <release-name> -n <namespace>
helm install <release-name> ./my-chart -n <namespace>
```
