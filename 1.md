
```powershell
az extension add --name log-analytics
```


```powershell
az monitor log-analytics query --workspace $ws --analytics-query "AzureActivity | where ResourceProviderValue =~ 'MICROSOFT.APIMANAGEMENT' | where OperationNameValue has 'namedValues/write' | where _ResourceId has 'apim-ads-cus-entbusops-prd-ext-apim-001' | project TimeGenerated, Caller, OperationNameValue, ActivityStatusValue | order by TimeGenerated asc" --timespan "P365D" -o table
```




Interpret an empty result carefully. It can mean the activity log isn't forwarded to that workspace, or the values are older than its retention. It doesn't mean they weren't created by hand.
