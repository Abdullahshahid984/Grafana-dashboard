Add Workload Identity federated credential support for additional clusters

**Premise**

Added support for automatically creating Workload Identity federated credentials for workloads on additional clusters beyond the primary cluster. This enables backup/restore validation, cluster migration, and disaster recovery scenarios across all environments.

During AKS backup and restore validation, we restored DEV workloads to aks-bfhaks-ihub-eus2-poc-02. Pods got stuck in Init state with:

AADSTS700211: No matching federated identity record found for presented 
assertion issuer 'https://eastus2.oic.prod-aks.azure.com/...'

Each AKS cluster has a unique OIDC issuer URL. The Managed Identity federated credentials only covered the original cluster's OIDC issuer. When pods ran on a different cluster, Entra ID rejected the token exchange causing CSI Secret Store to fail mounting Key Vault secrets.


add Workload Identity federated credential support for additional clusters via additional_clusters variable
