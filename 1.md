**Premise**
This PR fixes a critical blocking error in the Phase 2 deployment pipeline where initialization failed with `Error: Invalid workspace selection`.

**Root Cause**
The Release Pipeline uses a text-scraping automation script to calculate the target workspace dynamically. When the validation cluster name `"aks-bfhaks-ihub-eus2-dev-rst-01"` was hardcoded inside `phases/01-per-instance/locals.tf`, the script's regex loop mistakenly matched it and merged it onto the end of the Phase 2 workspace name, transforming `ws-bfhaks-ihub_workloads-dev-eus2-phase2` into a non-existent combined string.
